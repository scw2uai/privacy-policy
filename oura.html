Scarlett Health

Scarlett Health is a private, single-user personal-wellness integration used only by its operator.

What it does

With the operator's explicit OAuth consent, the integration requests only the daily scope from the Oura Cloud API and retrieves daily Readiness, Sleep, and Activity summaries.

Minimized information is processed with deterministic local rules. Same-day Readiness—or Sleep when Readiness is unavailable—may lower a suggested workout volume. It never increases workout volume and never changes nutrition targets.

Privacy and safety

Oura-sourced data and data derived from it are not provided to artificial-intelligence or machine-learning systems, sold, used for advertising, or made available to other users.

This integration provides personal wellness information only. It is not a medical device or medical advice and should not be used as the sole basis for exercise, nutrition, medication, or other healthcare decisions.
